# Custom Steve Chaos (CSC) — Paper-плагін

Мінігра у стилі "Custom Steve Chaos": хвилі мобів + бос кожні N хвиль,
6 класів зі своїми здібностями, 8 конкретних "важких предметів" (як в
оригіналі) що можна отримати безкоштовно після хвилі або купити в
магазині, і автоматичні соло PvP-дуелі без ставок.

## Вимоги

- Java 17+
- Maven 3.6+
- Paper/Spigot сервер **1.21.x** (можна змінити версію в `pom.xml` та
  `plugin.yml`, якщо твій сервер на іншій версії — дивись нижче
  "Інша версія сервера")

## Збірка

```bash
mvn package
```

Готовий файл з'явиться в `target/CustomSteveChaos-1.0.0.jar`. Кидай його
у папку `plugins/` свого сервера і перезапусти сервер (або `/reload`,
хоча перезапуск надійніший).

## Швидкий старт на сервері

1. Створи арену:
   ```
   /csc admin create arena1
   ```
2. Стань у точці, де гравці чекатимуть гру, і виконай:
   ```
   /csc admin setlobby arena1
   ```
3. Пройди по арені (плоский квадратний майданчик — як в оригіналі CSC)
   і постав кілька точок спавну мобів, ставши в різних місцях арени:
   ```
   /csc admin addmobspawn arena1
   ```
   Повтори це 4–8 разів по периметру арени — чим більше точок, тим
   рівномірніше спавняться хвилі.
4. (Опційно) постав точку, де спавниться бос:
   ```
   /csc admin setbossspawn arena1
   ```
5. Для автоматичних дуелей потрібна окрема пара точок (будь-де на
   карті, подалі одна від одної — наприклад дві маленькі платформи
   в стороні від основної арени):
   ```
   /csc admin setduelspawn1 arena1
   /csc admin setduelspawn2 arena1
   ```
   Якщо не поставити ці точки — дуелі просто не будуть траплятись на
   цій арені (решта гри працює нормально).
6. Стань там, де має стояти **сундук магазину**, і виконай (команда сама
   ставить блок сундука під ногами і одразу реєструє його):
   ```
   /csc admin addshopchest arena1
   ```
   Так само для **сундука кузні прокачки** (окремий сундук, будь-де на
   арені):
   ```
   /csc admin addupgradechest arena1
   ```
   Можна поставити кілька сундуків кожного типу (повторюй команду в
   інших місцях) — зручно для великих арен. Без жодного сундука
   магазин/кузня просто не будуть доступні гравцям на цій арені.
7. Налаштуй мінімальну/максимальну кількість гравців (за замовчуванням
   1–8):
   ```
   /csc admin setminplayers arena1 2
   /csc admin setmaxplayers arena1 8
   ```
8. Гравці заходять:
   ```
   /csc join arena1
   ```

Гра почнеться автоматично, коли набереться мінімум гравців (відлік —
`start-countdown-seconds` у конфігу).

## Команди для гравців

| Команда | Опис |
|---|---|
| `/csc join <арена>` | Приєднатись до гри |
| `/csc leave` | Вийти з гри |
| `/csc class` | Відкрити меню вибору класу (6 класів) |
| `/csc balance` | Показати баланс золота |
| `/csc lives` | Скільки життів залишилось у поточній грі |

Дуелі більше не викликаються командою — вони стартують автоматично
(дивись розділ "Дуелі" нижче). **Магазину й кузні прокачки теж немає як
команди** — на арені стоять окремі сундуки: правий клік по сундуку
магазину відкриває `/csc shop`-подібне меню, правий клік по сундуку
кузні відкриває прокачку (дивись розділи нижче).

Адмінські команди (`csc.admin`, за замовчуванням — оп):
`/csc admin create|setlobby|addmobspawn|setbossspawn|setduelspawn1|setduelspawn2|addshopchest|addupgradechest|setminplayers|setmaxplayers|reload <арена> [значення]`

## Класи

| Клас | Пасивка | Актив (ПКМ по предмету ✦ у 9 слоті) |
|---|---|---|
| Воїн | +15% уроду в ближньому бою | Вихор клинка — AoE удар навколо себе |
| Лучник | +20% уроду від стріл | Залп — 5 стріл одночасно |
| Алхімік | Повільна реген. здоров'я | Токсична колба — отруйна зона |
| Вампір | Лікування 10% від уроду в бою | Висмоктування крові — AoE + лікування |
| Маг | Магія ігнорує 20% броні | Вогняна куля |
| Громило | +4 серця, стійкість до відкидання | Удар щитом — приголомшення + відкидання |

Кожен клас отримує стартовий кіт (зброя + броня) одразу. **Активна
здібність (слот 9, ПКМ) з'являється лише після того, як гравець купить
предмет "Осколок" (Shard) у сундуку магазину за 2400 золота** —
безкоштовної роздачі Осколка немає, лише платна в магазині. Це
відтворює механіку оригіналу, де активний скіл класу розблоковується
окремо від самого класу і коштує грошей.

Лук лучника (і будь-який лук з нагороди за хвилю, дивись нижче)
**завжди назавжди зачарований Безкінечністю** — стріли не витрачаються.

## Життя

У кожного гравця **3 життя** за замовчуванням (`lives-per-player` у
конфігу). Коли удар мав би вбити гравця:

- Якщо залишилось життя — гравець не вмирає "насправді" (без дропу
  речей, без екрану смерті). Він лікується до повного хп, телепортується
  на точку лобі (`setlobby`), отримує 2с невразливості і повідомлення
  "Залишилось X/3" — і продовжує гру з тим самим інвентарем/здобиччю.
- Якщо це було останнє життя — гравець стає спектатором до кінця
  раунду (вибуває).
- Предмет "Відродження" (Rebirth, 7000 золота, одноразовий) дає
  +1 життя одразу при купівлі — це копія механіки Rebirth/Life Book з
  оригіналу, яка дозволяє "вийти за межі" стартових 3 життів.

Коли всі гравці вибули — раунд завершується і виплачується нагорода за
досягнуту хвилю.

## Безкоштовна нагорода "обери 1 з 8" після хвилі (прості речі)

Після зачистки кожної хвилі (включно з босом) **кожен живий гравець**
отримує вікно з **8 простими предметами** (випадково обраними з більшого
пулу — дивись нижче) — зброя/броня/розхідники, без жодних "важких"
ефектів — і обирає **один безкоштовно**:

| Предмет | Що видається |
|---|---|
| Залізний меч | Iron Sword (Гострота I; інколи §7+ бонус§7: Загибель членистоногих або Полум'я I) |
| Діамантовий меч | Diamond Sword (те саме, з шансом на той самий бонус) |
| Лук | Bow (Сила I, §bзавжди Безкінечність§7) + 16 стріл |
| Стріли | 16 звичайних стріл |
| Отруйні стріли | 8 §2тіпованих§7 стріл з ефектом Отрути |
| Стріли сповільнення | 8 тіпованих стріл з ефектом Сповільнення |
| Щит | Shield |
| Набір залізної броні | Шолом+нагрудник+поножі+чоботи (Захист I; кожна частина інколи §7+ бонус§7: Колючки/Thorns I) |
| Золоте яблуко | 2× Golden Apple |
| Зілля Сили | Potion of Strength |

Пул має **10 варіантів**, а вікно щоразу показує 8 випадкових з них —
тому набір пропозицій трохи міняється від хвилі до хвилі. Шанс бонусного
зачарування (Загибель членистоногих/Полум'я на мечі, Колючки на броні) —
**35%** на кожен предмет, рівень завжди I; якщо воно випало — цей
конкретний меч/частину броні вже можна прокачувати і в бонусному
зачаруванні теж (дивись "Кузня прокачки" нижче). Ці предмети видаються
напряму в інвентар (з викиданням на землю, якщо інвентар заповнений) і
ніяк не пов'язані з магазином чи золотом.

## Кузня прокачки (сундук, без команди)

Окремий сундук на арені (`/csc admin addupgradechest`) відкриває кузню —
поклади **будь-який** меч/лук/броню зі свого інвентарю (байдуже, зі
старту класу чи з нагороди за хвилю) у центральний слот, і кузня сама
покаже, які зачарування можна прокачати за золото:

- **Будь-який меч** завжди можна прокачувати в §eГострота§7 (I→V),
  навіть якщо він щойно виданий і без жодних зачарувань.
- **Будь-який лук** завжди можна прокачувати в §eСила§7 (I→V). Сама
  Безкінечність не прокачується і нікуди не зникає — вона завжди I.
- **Будь-яка броня** завжди можна прокачувати в §eЗахист§7 (I→IV).
- Якщо конкретний предмет вже має бонусне зачарування з нагороди за
  хвилю (Загибель членистоногих або Полум'я на мечі, Колючки на броні) —
  кузня покаже й окрему кнопку для прокачки саме цього зачарування
  (до свого максимуму: Загибель членистоногих V, Полум'я II, Колючки III).
  "Колючки" — це зачарування Thorns, не плутати з платним предметом
  "Шипи" (HeavyItem) з розділу нижче, вони не пов'язані.
- Предмет без бонусного зачарування — кнопки для нього просто немає,
  доки воно не з'явиться на цьому конкретному предметі іншим способом.

Кожен клік по кнопці апгрейду списує золото і одразу підвищує рівень
прямо на предметі в слоті; забери прокачаний предмет звичайним кліком
(він ніколи не "зникає" — якщо закрити кузню з предметом у слоті, його
автоматично повернуть у інвентар).

## 8 важких предметів (купуються лише за золото)

Окрема, "важлива" механіка — 8 предметів з реального списку CSC
(Мідас, 3 книги, Шипи, Відродження, Стрибок, Осколок). На відміну від
простих речей вище, **ці предмети не випадають безкоштовно ніколи** —
їх можна тільки купити за золото в сундуку магазину
(`/csc admin addshopchest`) у будь-який момент гри.

| Предмет | Базова ціна | Тип | Ефект |
|---|---|---|---|
| **Мідас** (Midas) | 1250 | одноразовий, з КД | ПКМ: миттєво вбиває звичайного моба хвилі (не боса, не гравця) і дає +190 золота. КД 45с. |
| **Книга Урону** (Damage Book) | 1550 (+400/стак) | стакається | +1 урону в ближньому бою, +0.5 урону луком за кожну книгу. |
| **Книга Життя** (Life Book) | 1400 (+300/стак) | стакається | +2 серця максимального здоров'я за кожну книгу. |
| **Книга Регенерації** (Regen Book) | 1350 (+300/стак) | стакається | +0.5 хп/сек пасивної реген. за кожну книгу. |
| **Шипи** (Spikes) | 1800 | одноразовий, з КД | ПКМ: 6с блокує 50% вхідного урону і відбиває 50% назад атакеру. КД 30с. |
| **Відродження** (Rebirth) | 7000 | одноразовий | Миттєво +1 життя в поточній грі. |
| **Стрибок** (Jump) | 1250 | одноразовий, з КД | ПКМ: різкий ривок вперед. КД 20с. |
| **Осколок** (Shard) | 2400 | одноразовий | Розблоковує активну здібність класу (слот 9). |

Точне зростання ціни книг за кожен стак в оригіналі ніде офіційно не
опубліковане — тут використані орієнтовні значення (`priceIncrement` у
`items/HeavyItem.java`), їх легко підправити під себе.

## Економіка та магазин

- Золото нараховується за вбивство мобів (`gold-per-kill`), вбивство
  боса (`gold-per-boss-kill`) і за виживання хвиль після завершення гри
  (`gold-per-wave-survived` × номер останньої хвилі), а також за
  перемогу в автоматичній дуелі (`duel-win-reward`).
- Сундук магазину відкриває список усіх 8 важких предметів з поточною
  ціною (яка росте для книг з кожним стаком) — більше немає
  гача-механіки "випадкової рідкості", як було у попередній версії.
- Баланс зберігається в `plugins/CustomSteveChaos/data/economy.yml`.

## Дуелі

Дуелі повністю **автоматичні** — викликати їх командою більше не
можна. Поки раунд триває (лише **соло-режим**, 1 на 1):

- Починаючи з хвилі `duel-start-after-wave` (за замовчуванням 3), одразу
  після зачистки кожної хвилі перевіряється, чи є хоча б двоє живих
  гравців, які зараз не в дуелі.
- Якщо так — **двоє випадкових** з них обираються, лікуються до повного
  хп і телепортуються на `duel-spawn-1`/`duel-spawn-2`. Решта гравців
  продовжують звичайну гру (чекають наступну хвилю) — дуель не зупиняє
  раунд.
- Під час дуелі справжньої смерті немає (без дропу речей, без екрану
  смерті) — фатальний удар перехоплюється і визначає переможця.
- **Ставок немає (v1-спрощення).** Переможець отримує фіксовану
  нагороду `duel-win-reward` золота (за замовчуванням 300). Поразка в
  дуелі **не** забирає одне з 3 основних життів гравця — це окрема
  система від PvE-життів.
- Після дуелі обидва гравці телепортуються назад туди, де стояли до
  дуелі, і продовжують PvE.
- Якщо гравець виходить з гри/сервера під час дуелі — це автоматично
  рахується як поразка (опонент отримує нагороду).

## Налаштування (config.yml)

```yaml
settings:

  boss-every-waves: 10
  lives-per-player: 3
  gold-per-kill: 5
  gold-per-boss-kill: 150
  gold-per-wave-survived: 10
  starting-gold: 100
  duel-win-reward: 300
  duel-start-after-wave: 3
```

## Інша версія сервера

Плагін написаний проти Paper API 1.21.1. Якщо твій сервер на іншій
версії:

- **1.20.4 і старіші**: зміни в `pom.xml` версію на `1.20.4-R0.1-SNAPSHOT`
  і в `src/main/java/com/oleh/csc/items/WaveRewardItem.java` та
  `items/UpgradeableEnchant.java` заміни нові назви зачарувань на старі:
  `SHARPNESS`→`DAMAGE_ALL`, `POWER`→`ARROW_DAMAGE`, `INFINITY`→
  `ARROW_INFINITE`, `PROTECTION`→`PROTECTION_ENVIRONMENTAL`,
  `BANE_OF_ARTHROPODS`→`DAMAGE_ARTHROPODS`, `FIRE_ASPECT`→`FIRE_ASPECT`
  (без змін), `THORNS`→`THORNS` (без змін). Те саме в
  `classes/ClassManager.java` для лука лучника. Там же
  `PotionMeta#setBasePotionType(PotionType.STRENGTH/POISON/SLOWNESS)`
  треба замінити на старий спосіб через
  `addCustomEffect(new PotionEffect(...))`.
- **1.21.2+**: мають зʼявитись нові неймспейс-аргументи для атрибутів
  (`Attribute.MAX_HEALTH` замість `Attribute.GENERIC_MAX_HEALTH`) —
  якщо збірка видає помилку на `Attribute.GENERIC_*`, заміни на коротку
  форму без `GENERIC_`.
- В `plugin.yml` поле `api-version` підніми до своєї версії (напр. `'1.21'`).

## Структура проєкту

```
src/main/java/com/oleh/csc/
  CSCPlugin.java          — головний клас плагіна
  CscConfig.java          — типізований доступ до config.yml
  arena/                  — модель арени (лобі, спавни, сундуки магазину/кузні) + завантаження/збереження
  game/                   — ігровий цикл: хвилі, бос, стан гри, 3 життя
  classes/                — 6 класів персонажів + здібності (Shard-гейтинг)
  items/                  — WaveRewardItem (пул простих безкоштовних речей
                             після хвилі, з випадковими бонус-зачаруваннями),
                             HeavyItem + HeavyItemManager (8 важких предметів,
                             лише платні в магазині), UpgradeableEnchant +
                             UpgradeManager (прокачка зачарувань за золото)
  economy/                — баланс золота (YAML)
  duel/                   — автоматичні соло-дуелі без ставок (AutoDuelManager)
  gui/                    — інвентарні меню (вибір класу, магазин, нагорода
                             за хвилю, кузня прокачки)
  listeners/              — бойова логіка, GUI-кліки, конект/дисконект,
                             відкриття сундуків магазину/кузні (ArenaChestListener)
  commands/               — /csc та підкоманди
  util/                   — допоміжні класи (ItemBuilder, Location (де)серіалізація, тощо)
```

## Відомі обмеження v1 (чесно попереджаю)

- Один тип боса (зомбі з бустнутими статами + періодична AoE-атака), а
  не 2 унікальні тематичні боси (Голем / Скорпіон) кожні свої хвилі, як
  в оригіналі.
- 6 класів замість 31+ в оригіналі — архітектура (enum `PlayerClass` +
  switch в `ClassManager`) зроблена так, щоб додати новий клас було
  швидко: додати константу в enum + case в `useAbility`/`applyKit`.
- 16 іменованих типів хвиль оригіналу (зомбі → дитячі зомбі → білі
  ведмеді → іфріти → броньовані зомбі → бандити → піґмени →
  силверфіші → ендерміти → павуки → токсичні павуки → отруйні павуки →
  скелети → скелети-вершники → мікс) тут замінені на узагальнене
  масштабування складності одного типу мобів за хвилю.
- Дуелі визначають переможця по фатальному удару (хто вбив — той
  виграв), а не по сумі нанесеного урону за фіксований таймер, як в
  оригіналі. Ставок немає — лише фіксована нагорода переможцю (явне
  спрощення на прохання користувача).
- Лише соло-режим (1 на 1) — командних режимів 1v1/2v2/6v6, як в
  оригіналі, тут немає (поки що, за свідомим рішенням).
- Немає формальної системи типів урону (істинний/отруйний/вогняний/
  відбиваючий/крадіжка життя) — є лише кілька окремих ефектів (Shard-
  здібності, Shipи, вампір-лайфстіл), не зведених у єдину систему.
- Одна універсальна арена замість 3 іменованих карт оригіналу (Balance
  / Fire / Obstacle Arena).
- Конкретний список простих речей у безкоштовній нагороді за хвилю
  (меч/лук/броня/стріли/яблуко/зілля) — це наш вибір простих предметів,
  а не точна копія оригінального дроп-листа (його точний склад не
  опублікований ніде відкрито) — головне, що він тепер відокремлений
  від платних важких предметів.
- Кузня прокачки впізнає лише 6 зачарувань (Гострота, Сила, Захист,
  Загибель членистоногих, Полум'я, Колючки/Thorns) — не повну таблицю
  зачарувань Minecraft. Легко розширити: додати новий варіант в
  `UpgradeableEnchant` і, якщо потрібно, у список бонусів у
  `WaveRewardItem`.
